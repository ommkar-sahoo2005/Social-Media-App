# Social Media Web Application

A full-stack social media web application developed using **React, Node.js, and SQL**. The project was built to gain hands-on experience in modern web development, covering frontend design, backend development, API integration, and database management.

## 🚀 Overview

This application provides a platform where users can interact with social media content through a dynamic web interface. It combines a React-based frontend with a Node.js backend and SQL database for handling application data.

## 🛠️ Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js
* **Database:** SQL
* **Languages:** JavaScript, SQL
* **Development Environment:** Visual Studio Code

## ✨ Features

* User authentication and account management
* User profile functionality
* Post creation and management
* Interaction with social media content
* Database integration for storing application data
* Frontend-backend communication through APIs
* Dynamic and interactive user interface

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone <repository-url>
cd Social-Media-App
```

### 2. Install dependencies

Navigate to the frontend and backend directories and install the required packages:

```bash
npm install
```

### 3. Configure the database

Set up the SQL database and update the database connection details according to your local environment.

### 4. Start the application

Run the backend and frontend separately using the appropriate commands:

```bash
npm start
```

or, if the project uses Vite:

```bash
npm run dev
```
